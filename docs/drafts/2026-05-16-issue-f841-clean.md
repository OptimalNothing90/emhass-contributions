`uvx ruff check` fails on master with:

```
Error: src/emhass/optimization.py:1168:9: F841 Local variable `p_grid_neg` is assigned to but never used
```

This fails the Code Quality workflow on every PR.

### Source

Introduced in commit `d50aacd4` (2026-01-20, "Settled with definitive cvxpy class implementation" — the large CVXPY class rewrite). The assignment sits inside `_add_battery_constraints`:

```python
def _add_battery_constraints(self, constraints, batt_stress_conf):
    ...
    p_sto_pos = self.vars["p_sto_pos"]
    p_sto_neg = self.vars["p_sto_neg"]
    p_grid_neg = self.vars["p_grid_neg"]   # ← line 1168, never read in this function
    E = self.vars["E"]
    ...
```

`p_sto_pos` and `p_sto_neg` are read later in the function. `p_grid_neg` is not. Looks like a copy-paste from earlier setup blocks: `p_grid_neg` is read inside `_add_main_power_balance_constraints` (line 858) and `_add_hybrid_inverter_constraints` (line 967), which open with the same three-variable pattern, but those two functions actually consume it.

### Timeline

- 2025-02-01: Code Quality workflow added with ruff (`.github/workflows/code-quality.yml`, first commit `233a9c7`).
- 2026-01-20: `p_grid_neg = self.vars["p_grid_neg"]` introduced at line 1168 (commit `d50aacd4`).
- 2026-01-20 → today: F841 reportable since then. Master CI has stayed green on merges, so the failure was either overlooked or admin-merged through. Running ruff locally on master `9627fc6` reproduces.

### Suggested fix

Two options, depending on intent:

**(a) Delete the line if the binding was a copy-paste artifact:**

```python
p_sto_pos = self.vars["p_sto_pos"]
p_sto_neg = self.vars["p_sto_neg"]
# p_grid_neg = self.vars["p_grid_neg"]   ← remove
E = self.vars["E"]
```

**(b) Keep it if a planned future constraint will read it**, and silence the lint with a documented `# noqa: F841` plus a TODO:

```python
p_grid_neg = self.vars["p_grid_neg"]  # noqa: F841 — reserved for upcoming grid-export constraint, see #<issue>
```

(a) is the safer default. Only pick (b) if there's a pending feature.
