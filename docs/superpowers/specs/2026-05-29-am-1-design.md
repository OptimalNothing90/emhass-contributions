## 1. Problem

EMHASS exposes a JSON HTTP API (config read/write, optimization triggers, run status, the
new liveness probe) but ships **no machine-readable contract**. Tool consumers — Node-RED
flow validators, EVCC adapters, Home Assistant cards, IDE tooling, LLM agents — must read
Python source or boot EMHASS to learn the endpoints, request bodies, and response shapes.
There is no `openapi.json` / `openapi.yaml` in the repo, and nothing keeps such a file in
sync with the routes if it were added by hand.

## 2. Goal

Commit a generated `openapi.json` (OpenAPI 3.1) describing the runtime + config JSON API,
plus `scripts/generate_openapi.py` that produces it deterministically from existing
single-sources-of-truth (`param_definitions.json`, the per-endpoint JSON Schema files), and
a test that fails CI if the committed file drifts from a fresh generation. Consumers get a
stable contract; the contract cannot silently rot because a new route or config param trips
a loud failure.

## 5. Concrete edits

### a. `scripts/generate_openapi.py`

Structure (stdlib only: `json`, `argparse`, `pathlib`, import `emhass.web_server`):

```python
SKIP = {"/", "/index", "/template", "/configuration"}

# path -> { method -> spec-builder }. Specs reference component schemas built below.
CURATED = {
    "/get-config": {"GET": ...},
    "/get-config/defaults": {"GET": ...},
    "/set-config": {"POST": ...},
    "/get-json": {"POST": ...},
    "/action/{action_name}": {"POST": ...},   # Quart's <action_name> -> {action_name}
    "/api/v1/last-run": {"GET": ...},
    "/healthz": {"GET": ...},                  # present once AC-4 merged
}

def discovered_routes() -> set[tuple[str, str]]:
    # from emhass.web_server import app; iterate app.url_map; normalise <x> -> {x}
    ...

def assert_no_undocumented(routes):
    for path, method in routes:
        if path in SKIP:
            continue
        if path not in CURATED or method not in CURATED[path]:
            raise SystemExit(f"undocumented route: {method} {path} — add to CURATED or SKIP")

def build_spec() -> dict:
    # info, components.schemas (Config built from param_definitions), paths from CURATED
    ...

def main():
    routes = discovered_routes()
    assert_no_undocumented(routes)
    spec = build_spec()
    out = Path("src/emhass/static/openapi.json")
    out.write_text(json.dumps(spec, indent=2, ensure_ascii=False) + "\n", encoding="utf-8")
```

Routes present in `CURATED` but absent from `url_map` (e.g. `/healthz` before AC-4 merges)
are silently omitted from the output — `CURATED` is a superset the generator filters by what
actually exists. Only the *reverse* (in `url_map`, not curated/skipped) is an error.

### b. `input` → OpenAPI schema mapping (config component)

Parse the `input` string by splitting on `.`; each leading `array` wraps the remainder in
`{"type": "array", "items": …}`. Base types:

| `input` base | schema | notes |
|---|---|---|
| `select` | `{"type": "string", "enum": <select_options>}` | enum from the param |
| `string` | `{"type": "string"}` | |
| `int` | `{"type": "integer"}` | |
| `float` | `{"type": "number"}` | |
| `boolean` | `{"type": "boolean"}` | |
| `time` | `{"type": "string"}` | e.g. `array.time` → array of time strings/objects; map base `time`→string |
| `object` | `{"type": "object"}` | e.g. `heat_topology`; opaque object stub |

Array nesting observed on master: `array.string`, `array.int`, `array.float`, `array.boolean`,
`array.time`, `array.array.float`. The recursive wrapper handles arbitrary `array.` depth.
Per param, attach `default` (from `default_value`), `description` (from `Description`, with
`unit` appended when `unit not in ("none", "", None)`), `title` (from `friendly_name`), and
`x-unit` (raw `unit`). **Unknown base `input` → `raise SystemExit`** so a future input type
forces an explicit mapping decision.

**`default` placement for array-typed params (verified 2026-05-29):** for `array.*` params,
`param_definitions.default_value` is the **per-element scalar template**, not an array — e.g.
`nominal_power_of_deferrable_loads` is `array.float` with `default_value = 3000`, while
`config_defaults.json` carries a concrete example `[3000.0, 750.0]`. So emit the scalar as
**`items.default`** (the per-element default), never as the array-level `default`. Scalar
params take `default` directly. This keeps the openapi `default` type-consistent with the
declared schema type.

### c. Component + path assembly
- `components.schemas.Config` = `{"type": "object", "properties": {<param>: <mapped schema>}}` built from every param across all sections of `param_definitions.json` (sections are UI grouping only — flatten to a single property map). The flatten **asserts key uniqueness across sections** and raises on a collision (don't silently overwrite — same self-policing as the route/input guards). On master today the keys are unique; the assert protects against a future duplicate.
- `/get-config`, `/get-config/defaults` 200 response → `{"$ref": "#/components/schemas/Config"}`.
- `/set-config` request body → `Config`; responses 201/400/500 (descriptions only).
- `/get-json` request body → `text/plain` raw YAML string; 201 response → `Config`; 400/500.
- `/action/{action_name}` request → `{"type": "object", "additionalProperties": true}`; 201 response → `{"type": "object"}` + `externalDocs` → `docs/plan_output_schema.md`. Document `action_name` as a path parameter (enum of the known action slugs if cheaply discoverable; else free string).
- `/api/v1/last-run` 200 → `$ref` (relative) to `docs/api/v1/last-run.schema.json`.
- `/healthz` 200 → `$ref` to `docs/api/healthz.schema.json`; 503 same schema (degraded).

### d. `src/emhass/static/openapi.json`
The committed output of running the generator. Created by `python scripts/generate_openapi.py`.

## 6. Test strategy

TDD per `superpowers:test-driven-development`. `tests/test_openapi.py`:

1. **Unit — input mapping:** `select`→enum, `int`→integer, `array.float`→array/number,
   `array.array.float`→nested arrays, unknown input→`SystemExit`.
2. **Unit — undocumented route guard:** feed a fake route set containing an unknown path →
   `assert_no_undocumented` raises; a fully-covered set does not.
3. **Validity:** generated spec has `openapi`, `info`, `paths`; every local `$ref` file
   target exists on disk.
4. **Drift (the CI check):** regenerate in-memory and assert equality with the committed
   `src/emhass/static/openapi.json`. Fails if a dev edits routes/params without regenerating.

Run order: write tests red, implement generator, generate the committed file, all green,
then `python -m pytest -q` full suite + `python -m ruff format --check` / `ruff check` on the
new files (no `uvx` on this machine — `python -m ruff`).

## 7. Acceptance criteria

- `python scripts/generate_openapi.py` writes a valid OpenAPI 3.1 `src/emhass/static/openapi.json`.
- `tests/test_openapi.py` covers mapping, route-guard, validity, drift; all green.
- Drift test fails if `openapi.json` is stale vs a fresh generation (proven by a deliberate desync in the test, or by review reasoning).
- Generator imports no package outside the stdlib + `emhass`.
- Curated set exactly = §3 Decision #3; `/configuration` and HTML routes absent from `paths`.
- `$ref`s to `docs/api/v1/last-run.schema.json` and `docs/api/healthz.schema.json` resolve (AC-4 merged first).
- Full suite passes; `ruff` clean on new files.
- `emhass-pr-reviewer` pass from main session; AGENTS.md §3/§5/§6 compliant.

## 8. Out of scope

- **AM-2 — defaults-drift guard** (Decision #11, reframed by live verification). No current drift exists; the near-term feasible item is a **CI test asserting shared scalar defaults agree** between `param_definitions.json` and `config_defaults.json` (prevents recurrence). Full generation/elimination of `config_defaults` is NOT feasible today (it is a runnable example config with multi-load arrays + 8 runtime-only keys param_def lacks) and is a deeper, maintainer-signed-off redesign. AM-1 includes `default` from the SoT (param_def) now; the openapi `default` is the *intended* runtime default (maintainer-aligned via #845, not code-enforced) — caveat stated in `info.description`.
- **AM-1b** — structured `/action/*` request payloads (per-action schemas). Separate card, blocked on AC-2b.
- **Structured plan-output JSON Schema** — kept as `plan_output_schema.md` (markdown SoT); linked via externalDocs only (Decision #7).
- **Secrets / `/configuration`** — setup-time browser concern, not a runtime contract (Decision #4). No secrets endpoint, no gap note.
- **A served `/openapi.json` route** in `web_server.py` — file is committed only; serving it at runtime is a possible follow-up.
- **`/get-json` HTML-page routes, `/`, `/index`, `/template`** — non-API.
- **Any new runtime/test dependency** (openapi validators, pydantic). Validity test is structural + `$ref`-existence, stdlib only.
- **A new `.github/workflows` file** — drift check rides the existing `python-test.yml` via the pytest test (Decision #9).
